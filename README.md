# Strona Fundacji Konor-Kład-Medyk – fundacjakkm.pl

- **Treść strony** edytujemy w panelu: https://app.pagescms.org (plik `dane/strona.json`).
- **Zdjęcia** trafiają do `szablon/img`, **dokumenty** do `szablon/dokumenty`.
- Po każdym zapisie Netlify sam buduje stronę (`node build.js`) i publikuje ją na fundacjakkm.pl w 1–2 minuty.
- Układu i wyglądu (`szablon/`) nie edytujemy w panelu.
